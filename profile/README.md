# Rootine

Welcome to the home of the **Rootine** project!

## Get started

New to the project? Follow the **[Getting Started guide](https://github.com/k6-rootine/.github/blob/main/getstarted.md)** to set everything up.

## Repositories

| Repository | Description |
|---|---|
| [**rootine**](https://github.com/k6-rootine/rootine) | The main project repository |
| [**k6-rootine.github.io**](https://github.com/k6-rootine/k6-rootine.github.io) | The landing page that links to all our other sites |
| [**treemaker**](https://github.com/k6-rootine/treemaker) | The Pascal program used to generate each tree |
| [**analysedescendante**](https://github.com/k6-rootine/analysedescendante) | The website for the top-down analysis ([open it](https://k6-rootine.github.io/analysedescendante/)) |
| [**docs**](https://github.com/k6-rootine/docs) | Documentation for all units of the main project ([read it](https://k6-rootine.github.io/docs/)) |

> [!IMPORTANT]
> To use the top-down analysis website, you first need to download `analyse.json` from the [landing page](https://k6-rootine.github.io/) and load it into the site.

Happy coding!
